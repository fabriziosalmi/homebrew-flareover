# homebrew-flareover

Homebrew tap for **[flareover](https://github.com/fabriziosalmi/flareover)** — a deterministic engine
that migrates a Cloudflare zone onto EU-sovereign, self-hosted infrastructure, with a 0%
false-positive contract (it never emits config that silently changes behavior).

## Install

```bash
brew install fabriziosalmi/flareover/flareover
```

The formula here is published automatically by GoReleaser on every
[flareover release](https://github.com/fabriziosalmi/flareover/releases). AGPL-3.0.
